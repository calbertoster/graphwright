# Graphwright

Human-facing views for [codegraph](https://github.com/colbymchenry/codegraph) indexes: render any symbol's neighborhood as an SVG, or generate a browsable markdown wiki of your codebase — from the index codegraph already built, in any repo, with zero runtime dependencies.

The committed design lives in [SPEC.md](SPEC.md).

```bash
graphwright view sayHello --depth 2 -o invite.svg          # neighborhood graph
graphwright wiki --out docs/codegraph-wiki                 # generated wiki
```

Requires Node ≥ 22.5 and a project indexed with `codegraph init`. Graphviz (`dot`) is optional — without it, `view` writes a `.dot` file (or prints DOT text to stdout) instead of an SVG, with a notice on stderr.

## `graphwright view <symbol>`

Renders the filtered neighborhood of a symbol: resolve it in the index, walk the graph out to `--depth` hops, and emit SVG/DOT/Mermaid.

```
graphwright view <symbol> [--depth 2] [--direction both|callers|callees]
                 [--kinds calls,references,imports] [--format svg|dot|mermaid]
                 [-o out.svg] [--pick N] [--force] [--project <path>]
```

- `--depth <n>` — traversal depth (default `2`).
- `--direction both|callers|callees` — which way to follow edges from the origin symbol (default `both`).
- `--kinds <k1,k2,...>` — comma-separated edge kinds to traverse (default `calls,references,imports`; `contains` is excluded by default — see SPEC.md §2 for why it's excluded even for class symbols).
- `--format svg|dot|mermaid` — output format (default `svg`).
- `-o, --output <path>` — write to a file instead of stdout.
- `--pick N` — when the symbol name is ambiguous, select candidate `N` from the list printed on a prior run.
- `--force` — raise the neighborhood size cap from 300 to 1500 nodes.
- `--project <path>` — project directory to search for `.codegraph/` (overrides walking up from the current directory).

Exit codes: `0` success, `2` no codegraph index found, `3` symbol not found or ambiguous (candidates/suggestions are printed to stderr).

## `graphwright wiki`

Generates a browsable markdown wiki from the index: an `index.md` group table plus one page per group (files grouped by directory-path prefix).

```
graphwright wiki [--out docs/codegraph-wiki] [--group-depth 2]
                 [--banner "<template>"] [--max-diagram-edges 150] [--project <path>]
```

- `--out <dir>` — output directory (default `docs/codegraph-wiki`).
- `--group-depth <n>` — number of leading directory segments used to form each group (default `2`).
- `--banner <template>` — banner text prepended to every page; supports `{cmd}` (the invoked command line) and `{date}` (today's date — using it opts out of byte-identical determinism between runs). Default: `> Generated by graphwright wiki — do not hand-edit. Regenerate: \`{cmd}\``.
- `--max-diagram-edges <n>` — cap on a group's intra-group diagram edges before falling back to a plain edge list (default `150`).
- `--project <path>` — project directory to search for `.codegraph/` (overrides walking up from the current directory).

Rerunning `wiki` fully rewrites the output directory (stale group pages from a shrunk index are removed) and, with the default banner, produces byte-identical output for an unchanged index.
